## 🚀 **Installation et Exécution**


1. **Construire les images Docker et lancer les containeurs :**  
   ```bash
   docker-compose up -d
   ```
   
2. **Accéder à l'interface streamlit :**  
   Rendez-vous sur [http://localhost:8000](http://localhost:8000)
